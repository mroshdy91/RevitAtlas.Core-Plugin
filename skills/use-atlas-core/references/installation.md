# Agent-assisted setup

Run `scripts/atlas-setup.ps1 -Action Doctor` before setup. When the user has authorized installation, use `-Action Install`; the helper downloads the pinned public Core runtime and verifies its archive, manifest and installer hashes before execution. Save work and close Revit normally if the helper requests it. Reconnect the client after setup and verify the actual year, engine and interface through `atlas_status`. Never paste or expose credentials. If a result is uncertain, recover the original operation identity. The runtime installer retains an `active-install.json` receipt. With Revit and the broker closed, use the installed `install-runtime.ps1 -Action Rollback -Receipt <retained receipt path>` to restore its prior selection. Rollback preserves work, package files and existing credentials; do not clear the separate v1 credential or the local development connection.
